## TIMEOUT PROTECTION

Without Timeout:
  Start ─────────────────────────────────────────────> ???
  (Job could run indefinitely if HasData API hangs)

With 10-Minute Timeout:
  Start ─────────────────────────> 10:00 (TIMEOUT)
        │                          │
        Normal completion          Force stop if exceeds
        (typically 6 min)          (clear error message)


## ENRICHMENT OPTIMIZATION LOGIC

Step 1: Get all properties from Listing API
  [P1:$500k] [P2:$450k] [P3:$400k] ... [P41:$150k]

Step 2: Sort by price (descending)
  [P1:$500k] [P2:$450k] [P3:$400k] [P4:$380k] ... [P20:$280k] | [P21:$270k] ... [P41:$150k]
                                                                  ↑
                                                                  Lower-priority properties
                                                                  (not enriched)

Step 3: Enrich top 20 only
  [P1:$500k ✅] [P2:$450k ✅] [P3:$400k ✅] ... [P20:$280k ✅] | [P21:$270k ⏭️] ... [P41:$150k ⏭️]

Rationale:
  - Optimizer selects top 5-10 properties by score
  - Higher-price properties more likely to be selected
  - Enriching bottom 21 properties wastes API calls
  - User won't notice missing yearBuilt on properties they won't select


## REAL-WORLD SCENARIO

8-Location Search (Typical User Workflow):
  Locations: Peoria IL, Chicago IL, Austin TX, Dallas TX, Phoenix AZ, Nashville TN, Atlanta GA, Tampa FL
  Budget: $500,000
  Max Properties: 5

BEFORE (Sequential):
  00:00 - Start Location 1 (Peoria, IL)
  06:00 - Complete Location 1 (41 properties enriched)
  06:01 - Start Location 2 (Chicago, IL)
  12:01 - Complete Location 2 (41 properties enriched)
  12:02 - Start Location 3 (Austin, TX)
  18:02 - Complete Location 3 (41 properties enriched)
  ...
  48:08 - Complete Location 8 (Tampa, FL)
  48:09 - Run optimizer (select top 5 from 328 properties)
  48:10 - DONE (48 min 10 sec)

AFTER (Parallel):
  00:00 - Start ALL 8 locations simultaneously
  00:01 - Peoria: Found 50 properties, enriching top 20...
  00:02 - Chicago: Found 50 properties, enriching top 20...
  00:03 - Austin: Found 50 properties, enriching top 20...
  ... (all locations run in parallel)
  06:00 - ALL locations complete (slowest = Tampa at 6 min)
  06:01 - Run optimizer (select top 5 from 160 enriched properties)
  06:02 - DONE (6 min 2 sec)

  ★ 87% FASTER (48 min → 6 min)
  ★ 51% FEWER API CALLS (328 → 160)
  ★ Same quality results (optimizer still picks best 5)
